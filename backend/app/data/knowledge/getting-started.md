# Nền tảng VicAI

VicAI là trợ lý AI có kiến trúc module gồm: model orchestration, memory, RAG và tool calling.

## Chế độ trả lời

- normal: cân bằng độ sâu và tốc độ.
- deep: ưu tiên suy luận sâu.
- fast: ưu tiên phản hồi nhanh.
- teach: giải thích như gia sư.
- code: tập trung vào code sạch.
- summary: tóm tắt nội dung dài.
